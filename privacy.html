Privacy Policy

Last updated: October 17, 2026

Why Japan Tools ("the tool") is used only by the owner of the YouTube channel Why Japan (@WhyJapanLocal) to manage that channel.

Data the tool accesses

With the channel owner's permission, the tool uses the YouTube Data API and the YouTube Analytics API to access the channel's own videos, playlists, captions, thumbnails, and analytics.

How the data is used

The data is used only to upload and schedule the channel's own videos and to review the channel's own performance. It is not sold, shared with third parties, or used for advertising.

Where the data is stored

Access tokens and any downloaded statistics are stored only on the channel owner's own computer. You can revoke the tool's access at any time at Google Account permissions.

YouTube Terms

The tool uses YouTube API Services. By using it, the user agrees to the YouTube Terms of Service and the Google Privacy Policy.
